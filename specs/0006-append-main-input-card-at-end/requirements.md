# requirements: 0006 メイン入力欄から追加したカードをファイル末尾に保存する

## 背景

ファイル上部に未分類カード、その下に名前付きグループがあるとき、メイン入力欄から追加したカードは先頭の未分類グループ末尾に保存される。追加したばかりのカードが既存グループより上に現れ、見つけにくい。

## 目的

メイン入力欄から追加した未分類カードが、既存のカードやグループの後に現れ、保存先 Markdown ファイルでも最後に記録されるようにする。

## スコープ

- メイン入力欄からのカード追加位置と、追加後の表示・保存・再読み込み時の順序。
- 未分類カードとしての扱いを維持したまま、名前付きグループの後ろにも追加できるようにする。

## スコープ外

- 返信欄からの追加、グループ内への挿入、ドラッグ＆ドロップによる移動の位置変更。
- 既存カードやグループの並び替え。

## 受入基準

- [ ] AC1: 先頭に未分類カード、その後ろに名前付きグループがあるファイルでメイン入力欄からカードを追加すると、新規カードは画面上で最後に表示され、保存先 Markdown ファイルでも既存の全グループと全カードの後に記録される。
- [ ] AC2: 名前付きグループだけがあるファイルでも、追加カードは名前付きグループに属さない未分類カードとしてファイル末尾に保存される。
- [ ] AC3: 名前付きグループがないファイルでも、追加カードは既存カードの後に保存される。続けて複数枚追加した場合は入力順に末尾へ並ぶ。
- [ ] AC4: 追加前からあるカードの内容・所属グループ・相互の順序は変わらない。
- [ ] AC5: 保存先ファイルを再読み込みした後も、AC1〜AC4 の順序と未分類・名前付きグループの区別が保たれる。
