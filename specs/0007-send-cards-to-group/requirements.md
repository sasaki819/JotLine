# requirements: 0007 カードの右クリックメニューからグループへ移動する

## 背景

現在、右クリックメニューにはグループの新規作成・グループ化解除などがあるが、既存グループを名前で選んでカードをその末尾へ移動する操作はない。既存のグループへカードを整理する操作を右クリックメニューから行えるようにする。

## 目的

カードを1枚または複数枚選び、既存グループを指定してその末尾へまとめて移動できるようにする。複数カードの相対的な並び順を維持し、現在所属しているグループの末尾への並べ替えにも利用できるようにする。未分類に戻す操作は「Ungroup（グループ解除）」として、名前付きグループの候補と区切って提供する。

## スコープ

- カードの単一選択・複数選択時の右クリックメニューに「Send to group（グループへ移動）」を追加する。
- 現在の JotLine ビューで開いているファイルの既存の名前付きグループを、表示順にサブメニューへ列挙する。
- サブメニューの名前付きグループ一覧の下に区切り線を置き、独立した「Ungroup（グループ解除）」の選択肢を表示する。
- カードのグループ解除は、本サブメニューと既存の単一・複数カードのグループ解除操作で、対象カードをファイル末尾の未分類グループへ配置する規則に統一する。
- 指定したグループの末尾への移動と、既存の保存・アンドゥ／リドゥへの対応。
- 既存の選択操作と日本語・英語の表示に合わせたメニューの追加。

## スコープ外

- 別ファイルのグループへの移動。
- このメニューからの名前付きグループ新規作成・名前変更。
- スレッド単位の「スレッド解散」操作の動作変更。
- カードのコピー操作やドラッグ＆ドロップの変更。
- カードの選択方法自体の変更。

## 受入基準

- [ ] AC1: 1枚だけが対象の場合と複数枚が対象の場合の両方で、右クリックメニューから「Send to group（グループへ移動）」のサブメニューを開ける。既存の日本語・英語の表示規則に従う。
- [ ] AC2: サブメニューは現在の既存の名前付きグループ名を JotLine 上のグループの並び順で表示する。現在所属している名前付きグループも候補に含める。同名のグループが複数ある場合も別の候補として扱い、選択したグループへ移動する。
- [ ] AC3: 名前付きグループを選ぶと、対象カードは元の位置から取り除かれ、指定グループに残るカードの後ろへ追加される。本文は変わらず、カードの消失や重複がなく、対象外のカードの相対順序と所属先も維持される。
- [ ] AC4: 既にグループに所属しているカードを、別グループにも現在の所属グループの末尾にも移動できる。現在の所属グループに移動した場合も、移動先の名前を維持する。
- [ ] AC5: 選択済みカード上で右クリックして実行すると、選択中の全カードを対象とする。未選択カードを右クリックした場合は、既存の仕様どおりその1枚だけを対象とする。
- [ ] AC6: 名前付きグループへの移動とカードのグループ解除では、複数カードは選択した順番ではなく、実行前の JotLine 上の並び順（グループの順序、各グループ内の順序）を維持して末尾に並ぶ。移動先の内外に選択カードが混在する場合も同様とする。
- [ ] AC7: 移動またはカードのグループ解除後の所属先と並び順が保存され、再読み込み後も維持される。変更を伴う1回の操作はアンドゥ1回で操作前へ戻せ、リドゥ1回で操作後へ戻せる。複数カードもまとめて扱う。
- [ ] AC8: メニューを閉じて移動先を選ばなかった場合や移動先候補がない場合は、カードを移動しない。保存に失敗した場合は操作前のカード配置を保ち、既存のエラー通知により失敗を認識できる。
- [ ] AC9: 未分類グループを通常の移動先名として列挙せず、「未分類に移動」という選択肢も表示しない。名前付きグループ候補と区切り線で分離した「Ungroup（グループ解除）」をサブメニュー内に表示する。名前付きグループ候補がない場合も、解除対象があればグループ解除を利用できる。
- [ ] AC10: 「Ungroup（グループ解除）」を選ぶと、対象カードを元の配置から取り除き、ファイル末尾の未分類（デフォルト）グループの末尾へ、実行前の並び順を維持して配置する。末尾に未分類グループがなければ、ファイル末尾に新しい未分類グループを作成する。途中に未分類グループがあっても、それを移動先として利用しない。
- [ ] AC11: グループ解除の対象に元のグループの全カードが含まれる場合も、その場でグループ名だけを外す処理ではなく、ファイル末尾へ配置する。既存の単一・複数カードのグループ解除も同じ規則にする。スレッド単位の「スレッド解散」は既存の位置を保つ動作を維持する。
