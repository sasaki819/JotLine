# 03. チートシート（普段使いの早見表）

## 概要

AIco の日常運用でよく使うスキルとコマンドを逆引きできる早見表です。  
全 21 スキルを最初から覚える必要はありません。まずは **基本 7 スキル** だけ押さえれば日々の開発を回せます。

## まず覚える基本 7 スキル

| 場面 | スキル名 | AI への声かけ例 |
| :--- | :--- | :--- |
| いま何の途中か分からない・再開したい | `aico-ticket-status` | 「今の状況を確認して次のアクションを教えて」 |
| ぼんやりした相談・方針の壁打ちをしたい | `aico-discuss` | 「〇〇の方針について相談したい」 |
| やることをチケットにしたい | `aico-create-ticket` | 「〇〇のチケットを起票して」 |
| 着手して作業ブランチを作りたい | `aico-ticket-start` | 「DoR に合意するので作業を開始して」 |
| 調査して実装計画（`plan.md`）を作りたい | `aico-ticket-plan` | 「現状を調査して実装計画を作って」 |
| 承認した計画に沿って実装・テストを進めたい | `aico-ticket-implement` | 「計画を承認するので実装を進めて」 |
| 完了確認してクローズしたい | `aico-ticket-close` | 「DoD を確認してクローズして」 |

## 目的別逆引き（全 21 スキル）

### チケットを進める

| やりたいこと | スキル名 | 実行ブランチの目安 |
| :--- | :--- | :--- |
| チケットを新規起票する | `aico-create-ticket` | 統合ブランチ |
| DoR を合意して作業ブランチを作る | `aico-ticket-start` | 統合 → 作業ブランチ |
| 調査して `plan.md` を作る | `aico-ticket-plan` | 作業ブランチ |
| 設計書・仕様書を作成・更新する（必要な時のみ） | `aico-ticket-design` | 作業ブランチ |
| 計画に沿って実装・テストを行う | `aico-ticket-implement` | 作業ブランチ |
| PR / MR 用の Title と Description を作る（任意） | `aico-ticket-pr` | 作業ブランチ |
| DoD 確認・完了確定・統合後の一覧更新を行う | `aico-ticket-close` | 作業ブランチ → 統合ブランチ |
| 進行中・起票済みのチケットを中止する | `aico-ticket-cancel` | 作業／統合ブランチ |
| 現在地を確認して次スキルを提案してもらう | `aico-ticket-status` | どちらでも可 |

### レビューを回す

| やりたいこと | スキル名 | 担当 |
| :--- | :--- | :--- |
| 独立ワーカーでレビュー、または人間レビュー指摘を記録する | `aico-review` | AI（独立ワーカー）／人間 |
| 指摘一覧を見て「直す／見送る」を選ぶ | `aico-review-triage` | **人間が決定** |
| 採用した指摘をすべて修正してもらう | `aico-review-fix` | AI |
| 修正結果を独立ワーカーに再確認してもらう | `aico-review-recheck` | AI（独立ワーカー） |

### 相談・設計判断・定常作業・運用メンテ

| やりたいこと | スキル名 | ひとこと説明 |
| :--- | :--- | :--- |
| 相談・壁打ちを議事録へ残す | `aico-discuss` | テーマ未定でも開始できる |
| 複数の作業に効く重要な設計判断を残す | `aico-create-adr` | 背景・選択肢・採用理由を長期保存 |
| 繰り返す定常作業を手順書にする | `aico-create-runbook` | リリースや定期点検など |
| Runbook に沿って定常作業を実施・記録する | `aico-runbook-run` | 実施記録と異常引き継ぎを残す |
| 完了済みの古い記録を `archived/` へ移す | `aico-archive` | リンクを保ったまま一覧を整理 |
| 環境・同期・リンク切れを総合診断する | `aico-doctor` | 導入後や困った時に実行 |
| 管理記録の Markdown 品質規約を適用する | `aico-markdown-write` | 記録作成時に AI が自動適用 |
| AIco 自体の改善要望を構造化して出力する | `aico-feedback` | 機密情報を除いたフィードバック生成 |

## よく使うコマンド（人間向け）

ターミナルから直接実行したいときは `tools/aico.sh`（Windows は `tools\aico.bat`）を使います。

```bash
# 初期設定・再設定（利用ツールやブランチ変更時）
tools/aico.sh init

# 環境・設定・同期・リンク切れの診断
tools/aico.sh doctor

# aico-manifest.json 編集後に各ツールのワーカー・スキルを再同期
tools/aico.sh sync_agents

# 現在のチケット状況と次に使うべきスキルを確認
tools/aico.sh ticket_status

# ダッシュボード・各区分の一覧を再生成（統合ブランチ上で実行）
tools/aico.sh rebuild_indexes

# AIco 本体の新バージョン確認とアップデート
tools/aico.sh update --check
tools/aico.sh update
```

※各スキルの使い分けや基本ルールで迷ったときは [使いこなしガイド・FAQ](04.user-guide.md) を参照してください。
